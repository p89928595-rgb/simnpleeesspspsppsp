# Simple ESP (Fabric, Minecraft 26.2)

Client-Mod: Andere Spieler leuchten durch Wände, Liste mit Distanz oben rechts. Taste **V** = an/aus.

Nur in Singleplayer, auf eigenen Servern oder mit Erlaubnis des Serverbetreibers verwenden.

## Download
Reiter **Actions** -> letzter Lauf -> **Artifacts** -> `simple-esp`. Die .jar (ohne `-sources`) in den `mods`-Ordner legen, zusammen mit Fabric API (0.156.0+26.2). Java 25 nötig.
